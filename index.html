AccessiCode¶

Bienvenue dans la documentation utilisateur d'AccessiCode.

AccessiCode est un outil d'aide à l'analyse de l'accessibilité d'une page Web. Il permet d'exécuter différents contrôles inspirés du RGAA (Référentiel général d'amélioration de l'accessibilité) à partir du code HTML d'une page et, pour certains contrôles, d'une analyse par intelligence artificielle.

Que peut faire AccessiCode ?¶

AccessiCode peut notamment :

  • analyser le code HTML d'une page ;
  • examiner certains éléments visuels grâce à une analyse d'image ;
  • exécuter plusieurs contrôles RGAA ;
  • signaler des anomalies potentielles ;
  • identifier les situations nécessitant une vérification humaine ;
  • fournir des explications et des recommandations lorsque cela est possible.

Commencer¶

Si vous utilisez AccessiCode pour la première fois, consultez la page Prise en main.

Vous y apprendrez comment :

  1. fournir une page HTML à analyser ;
  2. lancer un audit ;
  3. réaliser une analyse d'image ;
  4. consulter les résultats.

Consultez ensuite Comprendre les résultats pour connaître la signification des différents statuts retournés par AccessiCode.

Important¶

AccessiCode est un outil d'aide au diagnostic.

Il ne délivre pas de certification de conformité et ne remplace pas un audit d'accessibilité réalisé par une personne compétente.

Certaines vérifications nécessitent une interprétation du contexte, des interactions avec la page ou l'utilisation de technologies d'assistance. Les résultats produits automatiquement doivent donc être vérifiés lorsqu'ils concernent des anomalies importantes ou lorsque l'outil indique qu'une revue humaine est nécessaire.
