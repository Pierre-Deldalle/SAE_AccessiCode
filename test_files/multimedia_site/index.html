Démonstration des tests multimédia

Cette page contient des exemples pour vérifier la détection des médias du critère RGAA 4.1. Les chemins audio et vidéo sont des emplacements de démonstration; ajoute des fichiers dans le dossier media pour pouvoir lire les médias dans un navigateur.
