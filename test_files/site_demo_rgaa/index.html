6. Tests pour le critère RGAA 7.2 - Alternatives aux scripts

Chaque script qui possède une alternative doit avoir une alternative pertinente lorsqu'il n'est pas disponible ou exécuté :

6.1. Script avec alternative pertinente (devrait PASS pour 7.2.1)

Lorsque JavaScript est désactivé, l'heure statique et le message explicatif sont affichés.

6.2. Script avec alternative vide (devrait FAIL pour 7.2.1)

Lorsque JavaScript est désactivé, rien n'est affiché, ce qui rend l'alternative non pertinente.

6.3. Script sans alternative (devrait être IGNORÉ pour 7.2.1)

Ce script n'a pas d'élément

6.4. Script avec alternative non pertinente (devrait FAIL pour 7.2.1)

Lorsque JavaScript est désactivé, seul un message d'activation est affiché, mais la validation du formulaire n'est pas disponible.

Section ajoutée pour tester le critère RGAA 7.5

7. Tests pour le critère RGAA 7.5 - Messages de statut

Les messages de statut doivent utiliser les rôles WAI-ARIA appropriés ou les attributs aria-live/aria-atomic selon leur type :

7.1. Messages d'état/succès (Critère 7.5.1)

Devraient utiliser role="status" OU aria-live="polite" + aria-atomic="true"

Sauvegarde réussie
Chargement terminé
Profil mis à jour
7.2. Messages d'erreur/suggestion (Critère 7.5.2)

Devraient utiliser role="alert" OU aria-live="assertive" + aria-atomic="true"

Erreur de validation du formulaire
Attention : votre session va expirer dans 2 minutes
Champ requis manquant
7.3. Messages de progression (Critère 7.5.3)

Devraient utiliser role="log", role="progressbar", ou role="status" OU aria-live="polite" OU (aria-live="polite" + aria-atomic="true")
