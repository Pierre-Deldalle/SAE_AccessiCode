6. Tests pour le critère RGAA 7.2 - Alternatives aux scripts

Chaque script qui possède une alternative doit avoir une alternative pertinente lorsqu'il n'est pas disponible ou exécuté :

6.1. Script avec alternative pertinente (devrait PASS pour 7.2.1)

Lorsque JavaScript est désactivé, l'heure statique et le message explicatif sont affichés.

6.2. Script avec alternative vide (devrait FAIL pour 7.2.1)

Lorsque JavaScript est désactivé, rien n'est affiché, ce qui rend l'alternative non pertinente.

6.3. Script sans alternative (devrait être IGNORÉ pour 7.2.1)

Ce script n'a pas d'élément

6.4. Script avec alternative non pertinente (devrait FAIL pour 7.2.1)

Lorsque JavaScript est désactivé, seul un message d'activation est affiché, mais la validation du formulaire n'est pas disponible.
