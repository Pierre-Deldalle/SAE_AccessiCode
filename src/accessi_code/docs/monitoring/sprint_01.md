#### Sprint 1 : Développement de l'interface de l'application Python avec Gradio (hors niveau 3)
**User Stories :**
- US 1.0.1 : En tant qu'utilisateur, quand je lance l'application, j'ai accès à une interface 
d'accueil à partir de laquelle je vais pouvoir utiliser l'application
DoR : /
DoD : Le programme lance une interface Gradio au lancement pour acceuillir l'utilisateur

- US 1.0.2 : En tant qu'utilisateur, je peux glisser-déposer des fichiers dans l'application pour qu'ils soient uploadés et utilisés par le programme.
DoR : Avoir le système d'analyse de données d'entrées (fichiers et autres) fait si on veut que les fichiers soient exploités par le programme.
DoD : Les fichiers uploadés sont stockés dans l'application et sont à disposition du programme pour la suite du processus

- US 1.0.3 : En tant qu'utilisateur, je peux écrire une URL d'un site web que je veux faire analyser pour que le programme puisse récupérer le HTML généré et des captures d'écrans à utiliser dans la suite du processus.
DoR : Savoir comment utiliser Playwright pour analyser une URL
DoD : L'URL envoyée par l'utilisateur est récupérée par le programme et peut-être utilisée pour analyser le site par la suite

- US 1.0.4 : En tant qu'utilisateur, j'ai accès à une page informative qui m'explique ce que permet de faire l'application et comment m'en servir.
DoR : Connaître le fonctionnement de l'application à expliquer à l'utilisateur
DoD : Les explications nécessaires sont présentes et un utilisateur qui ne connait pas l'application peut comprendre son utilité et comment l'utiliser

- US 1.0.5 : En tant qu'utilisateur, une fois l'audit terminé, j'ai accès à une page de rapport qui me permet de consulter l'accessibilité complète de mon site sur tous les tests
DoR : Connaître la façon dont est construit le modèle de données de réponse pour pouvoir l'utiliser dans la façon d'afficher ces réponses dans le rapport
DoD : L'interface complète du rapport est présente, codée de façon intelligente avec des composants réutilisables, etc, et peut se construire de façon adaptative selon le nombre de tests à afficher, etc.

**Livrables :**
Interface complète, fonctionnelle, compréhensible et fidèle à la maquette au plus possible, pour une utilisation de l'application de bout en bout, sans jamais devoir passer par autre chose que l'interface pour utiliser l'application.
